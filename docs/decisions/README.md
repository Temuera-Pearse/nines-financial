# Decision Records

This section contains architecture decision records for core financial design choices that have already been accepted.

## What This Section Contains

- numbered ADRs for ledger ownership, idempotency scope, reference immutability, settlement instruction naming, and deposit lifecycle rules

## How To Use This Section

- Read an ADR to understand why a locked design choice exists.
- Use ADRs to support review and future change proposals.
- Do not treat ADRs as replacements for [../architecture/caller-contracts/financial-caller-contracts_v1.md](../architecture/caller-contracts/financial-caller-contracts_v1.md); they explain rationale rather than restating full caller behavior.
