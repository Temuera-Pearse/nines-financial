# Caller Contracts Guide

This section holds the authoritative caller contract and the separate draft record of unresolved questions.

## Authoritative Source Of Truth

- The only authoritative source of truth for financial caller contracts is [financial-caller-contracts_v1.md](financial-caller-contracts_v1.md).
- Other documents may only summarize or extract subsets from that file.
- If any extracted flow or policy document diverges from the authoritative contract, the authoritative contract wins.

## Documents In This Section
